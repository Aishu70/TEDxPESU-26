# TEDxPESU-26
Official TEDxPESU 2026 website – Contrast in Convergence | A modern, responsive platform for event details, speakers, past events, and team highlights.

This repository contains the source code for the official website of **TEDxPESU 2026**, built with React, Vite, and Tailwind CSS.

---

## Prerequisites

Make sure you have the following installed on your local machine:
- **Node.js** (v16+ recommended)
- **npm** (comes packaged with Node.js)

---

## Getting Started Locally

Follow these steps to clone and run the project on your local machine:

### 1. Navigate to the Project Folder
Open your terminal and change directory into the cloned project folder:
```bash
cd TEDxPESU-26/"TEDxPESU'26"

```

### 2. Install Dependencies

Install all required project packages using npm:

```bash
npm install

```

### 3. Run the Development Server

Start the local Vite development server:

```bash
npm run dev

```

### 4. Open in Your Browser

Once the server starts, the terminal will output a local development URL (typically `http://localhost:5173/`). Click or copy-paste that link into your web browser to view the application live.

---

## Tech Stack

* **Framework/Bundler:** [Vite](https://vitejs.dev/)
* **UI Library:** React
* **Styling:** Tailwind CSS
